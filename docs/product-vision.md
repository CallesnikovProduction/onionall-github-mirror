# Onionall Brawler product direction

A local-first, Tor-native research workspace: DISCOVER → SELECT → CRAWL →
ARCHIVE → EXPLORE. Initial scale is one user and tens to hundreds of pages.
The next research view will project directed page and host relationships from
archived edges; it must not require recrawling to recover link provenance.

Safe Mode is default: explicit approval, same-origin scope, bounded depth and
unique-page budget, robots compliance, Tor-only fetches, observable failures and
bounded retry. Progress survives restart through Frontier; the catalog stores
research observations. Freedom Mode, external scraping, AI orchestration and
web UI are outside M4.1. Real-Tor qualification remains separate from deterministic
local acceptance.
