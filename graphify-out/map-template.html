Каноническая Storm-топология

CLI → CrawlService → CrawlExecution готовит ресурсы, запрашивает Admission и запускает worker. Frontier выдаёт leases; worker выполняет следующий pipeline:

Порядок parse filters: DurableDiscoveryFilter резервирует допустимые outlinks → ArchiveParseFilter записывает blob и каталог до parser emission.

Fetch / parse / index status → CapabilityArchiveStatusUpdaterBolt: сначала наблюдение в архиве, затем authenticated Frontier store. Планирование и retry остаются у Frontier.

Root crawler.flux — отдельная историческая топология. H2 не является scheduler. Локальный поиск — catalog search, без полноценного full-text index.
